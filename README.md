# One Dark Pro Flat for Mayoi

A standalone dark theme for Mayoi, adapted from [Binaryify’s One Dark Pro Flat](https://github.com/Binaryify/OneDark-Pro/blob/master/themes/OneDark-Pro-flat.json). The editor, sidebar, terminal, and status bar share a slate background. The sidebar resize handle highlights on hover and stays draggable. Idle borders that share Mayoi’s border color blend into the background.

## Install

Requires Mayoi 0.19.0 or later.

```sh
mayoi plugin install cl1107/mayoi-one-dark-pro-flat-plugin
```

Choose **View → Theme → Color Theme… → One Dark Pro Flat**. The value for `theme` in `settings.json` is `one-dark-pro-flat.flat`.

To uninstall, run `mayoi plugin remove one-dark-pro-flat`. For local development, run `mayoi plugin dev .` from the checkout.
